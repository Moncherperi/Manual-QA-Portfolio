## 🤖 Автоматизация тестирования (QA Automation)

Помимо ручного тестирования, я владею базовыми навыками автоматизации на языке Python. В рамках дипломного проекта разработан автономный скрипт:

* 🚀 **[Проект: Ip Detector (Python API Automation)](https://github.com/Moncherperi/homework-Ip_Detector))**
  * **Стек:** Python 3, Requests, REST API, JSON, ООП.
  * **Суть проекта:** Программа автоматически определяет текущий внешний IP-адрес пользователя (через API ipify), отправляет его в сервис ipinfo для получения подробных гео-данных (город, регион, координаты), упаковывает ответ в формат JSON и автоматически выгружает готовый файл в облачное хранилище через REST API Яндекс Диска. Код полностью задокументирован (Docstrings) и соответствует стандарту PEP8.
